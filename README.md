## Что я делал (кратко)

### Windows-инфраструктура и 1С
- Администрировал Windows Server 2012, VMware, SQL Management Studio.
- Обслуживал сервер 1С:Предприятие, АТС Mango, СКУД, СВН.
- Внедрял VPN-туннель, Prometheus + Grafana.
- Администрировал домен, почту, сайт компании.

### Samba + Active Directory + ACL
- Участвовал в миграции файловых серверов с Windows на Astra Linux.
- Переносил шары, настраивал Samba с интеграцией в AD.
- Новые шары делал уже сразу на Astra Linux с Windows NT ACL.
- Перевёл шары на `vfs_acl_xattr`, чтобы права из проводника держались.

### Корпоративный портал (WebPortal-gap-rt.ru)
- Собрал корпоративный портал для предприятия: единая точка входа
  для новостей, сервисов, календаря, сетевых ресурсов и чата.
- Стек: Python (FastAPI), React, SQLite, LDAP/AD, Nginx, systemd.
- Настроил аутентификацию через Active Directory (JWT + LDAP).
- Не программист — портал собран с использованием ИИ и готовых решений,
  архитектуру и логику продумывал сам.

### Zabbix на Astra Linux SE «Воронеж»
- Развернул Zabbix 7.0.10 + PostgreSQL 15 + Apache + PHP 8.2.
- Перенёс хосты со старого сервера вручную.
- Настроил Parsec, мандатные метки, `setfacl`.
- Ввёл сервер в домен AD, настроил LDAP + JIT provisioning.
- Настроил Email-оповещения через SMTP.
- Установил Zabbix Agent — триггеры заработали.

### OpenVPN — массовая генерация сертификатов
- Автоматизация не только для себя, но и для команды — любой
  сотрудник может запустить скрипт и получить сертификаты.
- Скрипты `gen_certs.sh`, `gen_ovpn.sh`, `sort_certs.sh`, `check_p12.sh`.
- Раздал туннельные IP, подготовил правила iptables.

### Squid + ufdbGuard
- Squid из репозитория, ufdbGuard собран из исходников.
- Настроил фильтрацию по чёрным спискам.

### Резервное копирование doc3files
- Ко мне обратились 1С-ники с задачей: копировать файлы
  документооборота с одного сервера на другой.
- Уточнил ТЗ: только добавление, без удаления и замены.
- rsync в режиме «только добавление» (без `--delete` и `--update`).
- Отчёты на почту через SMTP с авторизацией.
- cron раз в 30 минут, проверка статуса раз в день.

### СФПЗ (Docker) — обновление до 1.15
- Бэкап БД через `pg_dump`.
- Остановил и удалил только frontend/backend, postgres/minio не трогал.
- Обновление без потери данных.

### Диагностика зависаний диска (srv-1c-doc)
- Нашёл причину: 1С перегружает NVMe синхронными записями.
- Диск физически здоров, ФС чистая.
- Предложил фиксы: отключить энергосбережение NVMe, буферизация техжурнала.

### Другое
- Скрипт удаления старых версий 1С (VBScript + WMI).
- Gitea: развернул ВМ на Astra Linux SE «Воронеж» (2–4 ядра, 4 ГБ RAM),
  установку довёл до мастера настройки, дальнейшую настройку передал
